## The short version

Third-year CS undergrad at **VIT-AP University**. I work at the seam between machine learning and real infrastructure — federated training that can't move the data, multi-agent systems that need memory and tools, and backends that stay cheap while they scale.

I care about the parts that are easy to skip: reproducibility, failure handling, and getting a thing to work on a URL, not just on my machine.

## Selected work

<sub>Click a project to expand the technical detail.</sub>

<details>
<summary><b>&nbsp;FedCareX</b> — federated clinical intelligence &nbsp;<code>PyTorch</code> <code>Federated Learning</code></summary>

<br>

Privacy-preserving training across decentralized clinical nodes — **the model travels, the data never does.** I built the distributed training loop in PyTorch and solved the hard part: keeping weights consistent and convergence stable when nodes update out of sync.

- Distributed training workflow across independent nodes
- Aggregation that stays stable under non-IID, out-of-sync updates
- Data never leaves its source — privacy by architecture, not by policy

**Stack:** PyTorch · Federated Learning · Distributed Systems
[`→ repository`](https://github.com/Jyothireddy-pula)

</details>

<details>
<summary><b>&nbsp;SynapseFlow-AI</b> — agentic GenAI system &nbsp;<code>LLMs</code> <code>Multi-agent</code></summary>

<br>

A multi-agent architecture with reasoning and persistent memory, wired to tools so agents **carry out** workflows instead of just answering. Designed modular so new agents and tools drop in without touching the core.

- Reasoning + memory loop across cooperating agents
- Tool integration for real workflow automation
- Modular, extensible orchestration layer

**Stack:** LLMs · Multi-agent · Tool use / orchestration
[`→ repository`](https://github.com/Jyothireddy-pula)

</details>

<details>
<summary><b>&nbsp;GemmaSpatialX</b> — vision-language + spatial reasoning &nbsp;<code>Multimodal</code></summary>

<br>

A multimodal model combining visual understanding with spatial reasoning, so it holds context across a whole scene rather than treating each object in isolation.

- Vision + language fused for scene-level understanding
- Spatial reasoning for relationships between objects
- Stronger context retention in multi-object environments

**Stack:** Vision-Language · Multimodal · Spatial reasoning
[`→ repository`](https://github.com/Jyothireddy-pula)

</details>

<details>
<summary><b>&nbsp;Verto</b> — gesture-controlled 3D interface &nbsp;<code>Computer Vision</code> <code>HCI</code></summary>

<br>

A hologram-style interface you drive with your hands: vision models read gestures and map them to 3D interactions. An experiment in what human–computer interaction looks like without a mouse.

- Real-time gesture recognition from camera input
- Gesture -> 3D interaction mapping
- Explores post-mouse human–computer interaction

**Stack:** Computer Vision · HCI · Real-time
[`→ repository`](https://github.com/Jyothireddy-pula)

</details>
